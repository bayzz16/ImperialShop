# ImperialShop Beach-Paper Packs

- **Java Edition:** Minecraft Java 1.21.1 resource pack (pack format 34).
- **Bedrock Edition:** Bedrock resource pack for 1.20.0+ clients; import directly or distribute through Geyser/Floodgate resource-pack configuration.

The included PNG is a paper-item texture with warm parchment, sand, seafoam, and ocean colors. It changes the vanilla PAPER item texture only; it does not replace the entire inventory GUI background. Java and Bedrock use different resource-pack formats, so one pack cannot support every past and future game version. For Java versions outside 1.21.1, update pack_format to match the exact client version before distributing.
